# PT-B7 触りの直しの残り(説明書)

書いた人: 統合担当(10/21)。実装: relay:codex-impl。土台: main。
元: `docs/briefs/PT-B5-map-touch.md` §7 の表(全画面の棚卸し)。表の書いた時点から直った物があるかもしれないので、**直す前に今の画面で確かめ、直っている物は直さない**(報告に「直っていた」と書く)。

## 1. 決まり(どの直しにも当てる)
- 確認のダイアログは出さない(取り返しのつかない操作だけ。オーナーの決まり)。長押しで決めさせることもしない(OP-D1・OP-B2)。
- 取り返しの形にする: すぐ実行して取り消しの帯を出す、または実行の前の状態を残して戻せるようにする。取り消しの帯は今ある `ReForge/Sources/Game/UndoBand.swift` を使う(文言・秒・時計を止めるかを渡す)。新しい帯の部品を作らない。
- 押す物の当たりは 44pt 以上(`InkMetric.buttonHeight`・`rowHeight`)。見た目を大きくせずに当たりだけ広げてよい(`contentShape`・`frame(minWidth:minHeight:)`)。
- 説明・理由の文を足さない。押せない物はボタンにしない。画面の文言は表(`content/public/text/ja/*.json` の `ui.*`)に置く。

## 3. 漏れを防ぐ試験(ここが本体)
表の一点ずつの直しで終えず、同じ理由の漏れを機械で拾う:
- `ReForgeUITests` に、撮る起動(`-ReForgeScreenshot <画面>`。`ReForge/Sources/Debug/ScreenshotMode.swift`)の主な画面それぞれで、**押せる要素(button・`isHittable` な物)の枠が 44×44pt 以上**であることを確かめる試験を足す。外れた物は識別子と枠を全部出す(1 つ目で止めない)。地図のマス・地図の上の操作棒など、意図して別の大きさの物は、理由を書いた除外の表で外す(除外は最小に)。
- 取り消しの帯の試験: 設計の ✕・札の捨てる・失って続ける・技能付与で、押すとすぐ効き、帯が出て、帯の「戻す」で前の状態に戻る(本体の側で戻せるなら ReForgeCore の試験、アプリだけなら UI 試験)。

## 4. 確かめ
- ReForgeCore(Linux・hub)。重い処理は `systemd-run --user --scope -q -p MemoryMax=3G -p MemorySwapMax=0 nice ~/.local/bin/rf-swift-slot docker run --rm --cpus=3 --memory=3g --memory-swap=3g -v "$PWD":/w -w /w swift:6.1-noble swift test -j 3 --package-path ReForgeCore ...` で 1 本ずつ。
- アプリは Linux でコンパイルできない。静的な確かめ(`python3 tools/check-*.py`。`check-time-tint-shots.py` は除く)と `python3 tools/test_*.py` を全部通す。UI 試験は統合担当が macOS の CI で回す。
