## この単位で直す物
1. **地形の字の地の色**: 地図のマスの地の色(`TileStyle.background`)で、四角い枠のように見える物を見直す。水などの地の色は、隣のマスと境目の無い面として描く(1 マスずつの角の丸めや枠の線を描かない。地の色の明るさを地図の黒との差 15% 以内に抑える)。押せる物(ボタン)と同じ形(角丸の四角・枠線)を、地形に使わない。
2. **置いた物の字**: 置いた物(モジュール・建造物)を、塗った四角や枠の四角の字で描かない。種類ごとの字(`TilePalette` に種類 → 字の表。art-director の決め。仮の字を置く)にし、止まっている物は字を暗くする(今の `stopped` の色)。チェックボックス・ラジオボタンに似た形(□■☐☑○●)を、地図の字に使わないことを `TilePalette` のテストで確かめる。
3. **空のタブ**: タブは、その頁に見せる物が 1 つも無い間は出さない(開示の門に加え、頁の中身が空かを `FrameBuilder` が見て、`UIUnlocks` のタブを閉じたままにする)。頁ごとの「空」の決まり: 設計 = 試せる物も段も無い / ノート = 書き留めが 0 / 拠点 = 置いた物も研究も無い / 仲間 = ノアのほかの一員が 0。一度開いたタブは閉じない(今の開示と同じ)。
- 非公開の層の門(`uiGates`)はそのまま効く。公開の層の写真の撮る起動は、全部開く(今のまま)。

## テスト
- (Linux)空のタブ: 新しい世界(公開の層)で、仲間 0 なら仲間のタブが閉じている・一員を足すと開く・外しても閉じない。ほかの 3 つも同じ形。
- (Linux)`TilePalette`: 地図の字の表に、チェックボックス・ラジオボタンに似た字が無い。
- 画面の写真: 地図の画面が今の検査を通る。
