# 人が遊ぶ回(PT-01)の後の列 — 段 F0〜F4 への割り振り

書いた人: architect(統合担当)。もとは無料の範囲の決定(オーナー 2026-10-02。非公開の計画の free-range-cut v0.4 §12 と port-order §6.1)。
決まったこと: 無料の部分を先に作る。段は F0 → F1 → F2 → F3 → F4 の順で、段ごとに人が遊んで確かめてから次の段の単位を Codex に出す。PT-01 の前の列(README の「今の列」)はそのまま進める。

## 横の表示(PC 版の殻の配置の単位の後)
| 単位 | 中身 | 担当 | 説明書 |
|---|---|---|---|
| H-01 横の表示 | オーナーの案(2026-10-02): スマホは縦が既定、設定から横に切り替えられる。出す時期は使い魔の勧めで、PC 版の横の配置ができた段(Steam の PC 版の殻の配置の単位の後)。中身: `project.yml` の向き(縦の既定のまま横を足す)・設定の項目「横画面」・画面ごとの横の割り付け(方向のボタンは左右どちらかの親指の位置)・写真の検査に横を足す口(screens のジョブで全画面を縦と横の両方で撮る。安全域の外に物が無いかを確かめる) | Codex・U13・art-director | 要 |
- **iOS は SwiftUI で組み直し**: Android と PC は同じ SDL3 の殻なので横の配置のコードを共有できるが、iOS の画面は SwiftUI のままなので、共有できるのは「どこに何を置くか」の決まりだけ。iOS の横の画面は組み直しになる(steam-designer の M1 の工数に入っていない)。見込み: 主画面(地図・帯・足元カード・方向のボタン・タブ)で Codex の 2〜3 回分、ほかの画面(設計・ノート・拠点・仲間・設定・札・ゲームオーバー・タイトル・序)の横の確かめと直しで 3〜4 回分、写真の検査の横で 1 回分。合わせて Codex の 6〜8 回分。
- **配置の決まりは 1 つの表にする**: `HUDLayout`(PT-B5 で縦の値を作る)の値を、殻をまたいで読めるデータ(`content/public/ui/hud-layout.json`。部品の ID ごとに、縦と横それぞれの寄せる辺・並び・大きさ・利き手で入れ替えるか)にし、iOS の SwiftUI も SDL3 の殻もこの表を読む。殻ごとに値を持たない。
