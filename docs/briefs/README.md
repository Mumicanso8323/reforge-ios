# Codex に渡す説明書の列

Codex(relay:codex-impl)は 1 本ずつ回す。上から順に渡す。「渡せる」は依存がそろっていて、今すぐ回せるもの。
各説明書は統合担当(architect)が書き、マージのときに非公開の層を重ねた全体を統合担当が回す。
テストの置き場(F §4): まず `~/.local/bin/rf-note-test . --filter <テスト>`(note で回す)。Codex の作業場から note に ssh できなければ、予備の hub の `~/.local/bin/rf-swift-slot`(`--cpus=3`・`-j 3`)。実装の側は関わるテストだけを `--filter` で回し、全体は回さない。
