# PT-B5 地図の触り心地 — 方向のボタンで歩く・タップは選ぶ(Codex への説明書)

書いた人: architect(統合担当)。実装: Codex(relay:codex-impl)。土台: 統合の枝 `integration-c` の先頭(PT-B2 の後)。**最優先**(オーナーが今遊んでいる)。
なぜ: オーナーの言葉「マップ操作ことごとくスマホ操作しづらいな」。オーナーの決定(2026-10-02): 移動は**方向のボタン**。「直感的に操作できる感じがいいよ。基本ドラッグで移動向きをニュートラルに変更できて、戻すと停止。」スマホは**縦が既定**(横は設定から。PC 版の配置の後。この単位では作らないが、差し替えられる作りにする)。
物差し: 評価の軸「操作性」(OP-A1 反応・OP-A4 方向のボタンの追従・OP-B1〜B2 誤タップと取り返し・OP-C1 縦の親指の範囲・OP-C4 指の大きさ・OP-D1 隠れた操作・OP-D3 説明の文なしで分かるか)。具体的には、押せる所は 44pt 以上・主な操作は片手の親指で下半分・知らないと気付けない操作(長押し・隠れたスワイプ)を無くす・取り返せない誤タップを無くす・押してから 0.1 秒以内に見た目が変わる(game-craft の player-psychology-ux 原則 8・game-feel・accessibility・platform-stores の Apple HIG 44×44pt)。

## 1. 方向のボタン(仮想の操作棒)
### 形
- 地図の右下に、丸い台(直径 132pt。半透明の地の色 + 細い縁)と、その中のつまみ(直径 56pt)を常に出す。触れば分かる形にし、説明の文は出さない(台と、つまみの影が「動かせる」の印)。
- 台の中のどこを押しても、**押した点が中立**になる(押した瞬間に歩き出さない)。指を中立からずらした向きへ歩き続ける。つまみは指に付いて動く(台の縁まで。最大 48pt)。
- 止まる: 指を中立(遊びの円の中)に戻す。指を離す(**補い**。オーナーの言葉は「戻すと停止」。離したときも止めるのは使い魔の補い)。
- 速さは 1 つ(今の歩きの速さ。1 秒 4 マス)。ずらした量で速さを変えない(マスの地図で、速さの段を持つと止まる位置が読みにくいため)。

### 向きの丸め方(決めたこと・理由)
| 細部 | 決め | 理由 |
|---|---|---|
| 向きの数 | **8 方向**(45° ごと) | 本体の歩きは斜めにも進む。4 方向だと斜めの目印へジグザグになり、押し直しが増える |
| 切り替えの粘り | 隣の向きへ移るのは、境目を 8° 越えたとき | 境目の近くで向きが震えるのを防ぐ |
| 中立の幅(遊び) | 押した点から半径 14pt | 親指の自然なぶれ(数 pt)で歩き出さず、意図したずらしは 1 cm 弱で効く |
| 押した瞬間 | つまみが指の下へ即座に寄り、台の縁が明るくなる。中立を出た最初の 1 回だけ選択の触覚(軽) | 0.1 秒以内の見た目の反応。触覚は「歩き出した」合図だけにし、歩いている間は鳴らさない |
| 1 マスごとの間 | 置かない(歩きの速さのまま続けて歩く) | 間を置くと「押しているのに止まる」に見える。止まる位置は指を戻した時点の次のマスの中心 |
| 歩けないマス | 斜めなら、通れる方の軸へ**沿って滑る**(直前に動いた軸を先に、無ければ横を先に)。まっすぐ当たったら止まり、警告の触覚(弱)を 1 回と、台の縁を 1 度赤みに光らせる。同じ壁に当たり続けても触覚は繰り返さない(向きを変えたら、また鳴る) | 斜めの壁際で止まると「引っかかる」と感じる。当たったことは触覚と見た目の両方で伝える(触覚だけにしない) |
| 指が台の外へ出たとき | 台の外へ出ても追う(向きは中立からの向きのまま。つまみは台の縁で止まる)。指が地図の上を通っても、地図は動かない | OP-A4: 歩きながら指がずれても途切れない |
| 他の操作との関係 | 歩き出すと、行き先への歩き(`walk(to:)`)と、手の行為は取りやめる。足元カードは、歩いている間も足元のマスの物に替わり続ける | 操作棒を触ったら、いつでも自分の足に戻れる |

### 本体(Linux で確かめる)
- 命令 `.crew(.steer(direction: StickDirection?))` を足す(`StickDirection`: 8 方向。nil は止まる)。
- ノアの状態に `steer: StickDirection?`(任意。nil の間は保存に書かない。読み込んだ世界では nil)。毎ステップ、ノアの経路の残りが 2 マスを切ったら、その向きの次のマスを経路に足す。通れるかは今の歩きと同じ規則(記録した地形・置いたモジュールは通れない・霧の先は通れると仮定)。斜めの角の抜け方も今の経路と同じ。
- 当たったら、上の表のとおりに滑るか止まる。止まったステップで出来事 `DomainEvent.steerBlocked` を 1 回(向きが変わるまで再び出さない)。
- テスト(新しい `RFCrewTests/SteerTests.swift` など): 平地で東へ 1 秒で 4 マス進む・nil で次のマスの中心で止まる・斜めで北が壁なら東へ滑る・正面が壁なら止まって `steerBlocked` が 1 回だけ・`walk(to:)` で操作棒の歩きが消える・保存に `steer` が書かれない(凍らせた見本はバイトまで同じ)。

## 2. 地図のタップ・ドラッグ・拡大
| 操作 | 今 | これから | 理由 |
|---|---|---|---|
| タップ | すぐ歩く(確認なし) | **選ぶ**。そのマスに印を付け、足元カードをそのマスのカードにする(調べた内容 = 名前・鉱脈の見た目・残り回数・ノアの手ざわり を、カードの中に出す)。カードに「ここへ歩く」(44pt)。押すと経路の点線を出して歩く | 小さいマス(18pt)を指で正確に押せない。押し違いで歩き出すのが一番の不満の元。歩きは操作棒とカードのボタンに移す |
| 長押し | 0.5 秒で調べる(ふきだし) | **無くす**(調べるはタップに入った) | 知らないと気付けない操作 |
| 1 本指のドラッグ | 見回す | そのまま(見回す)。追従が外れたら、◎(48pt)で戻る | 地図を見回すのは指で引くのが自然 |
| ピンチ | 3 段に吸い付く | そのまま + 地図の左下に「＋」「−」(44pt)を足す。ダブルタップは使わない | ジェスチャだけの操作には、押せる代わりを置く |
| ノアのマスか ◎ をタップ | — | 選びを外し、足元カードをノアの足元に戻す | |
| 置くモード | 照準をもう一度タップすると建てる | 照準はタップで動かすだけ。建てるのは「ここに建てる」のボタンだけ | 2 度押しで建ってしまう |

- 選んだマスの印は、足元のマスの印と色を変える(選びは `InkColor.accent`)。調べたことで開く要素(U20)は、タップで選んだときに今の長押しと同じく開く。
- `GameStore.walk(to:)` を「選ぶ」と「歩く」の 2 つに分ける(`select(_:)`・`walkToSelection()`)。`inspect` は `select` から呼ぶ。

## 3. 下の割り付け(縦。iPhone 15 の 393×852pt で描く。SE の 375×667pt でも重ならないこと)
```
 ┌────────────── 393 ──────────────┐
 │  (安全域 上)                       │
 │ [状態の帯 ………………………]  [⚙ 52]   │ ← 見るだけの物。押す物は置かない
 │                                  │
 │              地図                 │
 │                                  │
 │ [＋]                              │
 │ [−]                   ╭────────╮ │
 │ [◎]                   │ 操作棒  │ │ ← 台 132pt。中心は右端から 82pt、
 │                       │ 132pt  │ │   足元カードの上端から 82pt
 │                       ╰────────╯ │
 ├──────────────────────────────────┤
 │ [夜作業] [寝る] / [決断の選択肢…]    │ ← 帯の押す物をここへ(44pt。出るときだけ)
 │ 足元カード(題 + 行為 44pt ×3 まで)  │
 ├──────────────────────────────────┤
 │ [地図][設計][ノート][拠点][仲間]      │ ← 44pt
 │  (安全域 下 34)                    │
 └──────────────────────────────────┘
```
- 操作棒の中心の高さは、画面の上から約 70%(片手の親指が自然に届く範囲)。地図の右下に重ねる(足元カードを横に狭めない)。
- 状態の帯の「夜作業 / 寝る」と決断の選択肢は、上の帯から**足元カードの上の行**へ移す(上の帯は親指が一番届かない所で、取り返せない選択がそこにあった)。決断の選択肢は物語の取り返せない選択なので、**タップで選び、取り消しの帯を出す**: 押すと選んだ選択肢が光り、帯に「〈選んだ選択肢〉 — 取り消す」(44pt)と残りの秒を 4 秒出す。その 4 秒の間は時計を止める(`GameStore.isPaused`)。取り消さなければ、4 秒で本体に決断を送る。取り消したら何も送らず、選択肢に戻る。長押しは強いない・確認のダイアログは出さない(オーナーの決まり)・誤タップは取り返せる(OP-B1・OP-B2・OP-D1)。帯の秒は「動きを減らす」の入でも数字で出す。
- 足元カードの中の押す物は最小 44pt(今の 36pt の `.quiet` を、地図の画面では使わない)。
- 割り付けは 1 つの型 `HUDLayout`(縦・横の 2 つの値。どの部品をどの辺のどこへ寄せるか・大きさ)にまとめ、画面はこの型だけを読んで並べる。この単位では縦の値だけを作り、横の値は「横の表示」の単位(F 段)で足す。利き手の左右の入れ替えも `HUDLayout` の左右反転で行う。

## 5. 記録で取る数(PT-B4 に足す)
| `kind` | 中身 | 何を測るか |
|---|---|---|
| `steer` | 操作棒で歩き出した・向きを変えた・止まった(理由: 中立・離した・当たった・ほかの命令)。マスと向き | 行き過ぎて戻った回数(止まってから 2 秒以内に逆向きへ歩き出した)を後で数える |
| `blocked` | `steerBlocked` が出た | 歩けないマスに当たった回数 |
| `select` | 地図のマスを選んだ。マス | 目印まで歩いて調べて戻る秒数(PT の手順で目印を決め、`steer` と `select` の時刻から数える) |
| `pan` | 見回しを 1 回終えた(動かした距離) | 地図を見回した回数 |
| `zoom` | 拡大・縮小した(段と、ピンチかボタンか) | 拡大縮小の回数 |
- 触った所の記録の行(`command`・`select`・`steer`・`pan`・`zoom`)に、画面の縦の 3 分割のどこを触ったか(`zone`: top・middle・bottom)を足す。下の 3 分の 1 だけで済んだ割合を「片手で済んだか」の目安にする。
- 数え方は `tools/playlog-summary.py`(PT-B4 に足す。標準のライブラリだけ)で、記録のファイルから上の数を表にする。

## 7. この単位に入れない物(全画面の棚卸しから。後の単位 PT-B7 へ)
全画面の棚卸し(押せる大きさ・親指の届き・隠れた操作・取り返せない誤タップ)で見つかった物のうち、地図と下の割り付けに関わらない物は、PT-B6 の後の **PT-B7 触りの直しの残り**にまとめる(統合担当が説明書にする):
| 画面 | 物 | 直し |
|---|---|---|
| 設計 | 工程の ▲▼✕ が 32pt で並び、✕ は即座に消す。名簿の含める/含めない 32pt。数の −/+ が幅 30pt。手がかりの ▸ が文字だけ | 44pt にし、✕ は取り消しを出す |
| 設計 | 札の「捨てる」がタップで即座 | すぐ捨て、取り消しの帯(4 秒)を出す |
| 拠点 | 手動の保存の「書く」(上書き)・「読む」(今の進みを捨てる)・「タイトルへ」がタップで即座。「タイトルへ」36pt | 上書きの前の保存を 1 つ残し、枠に「前に戻す」を出す。読む・タイトルへの前に、今の状態を自動の枠に残す(戻れる)。44pt |
| ゲームオーバー | 「失って続ける」がタップで即座。枠のボタン 36pt | 取り消しの帯(4 秒。その間は時計を止める)・44pt |
| 戦い | 「退く」36pt・帯が上 | 44pt。帯の押す物を下へ(PT-B5 と同じ形) |
| 札 | 札の「閉じる」が右上の 36pt。下へ引いて閉じられない | 下に 44pt の閉じる・下へ引いて閉じる |
| 状態の帯 | 横に隠れて流れる値 | 2 行に折り返す |
| 仲間 | 配属のチップが横に隠れる・押すと即座に替わる | 折り返し・今の配属をはっきり |
| 技能付与 | 付ける・付けないが即座。「付けない」36pt | 取り消しの帯(4 秒)・44pt |
**直し方の決まり**: 確認のダイアログは出さない(オーナーの決まり)。長押しで決めさせることもしない(OP-D1・OP-B2)。取り返しの形にする: すぐ実行して取り消しの帯を出す、または実行の前の状態を残して戻せるようにする。取り消しの帯は 1 つの部品(`UndoBand`。文言・秒・時計を止めるかを渡す)にし、PT-B5 の決断と PT-B7 で同じ物を使う。

原作(Web・マウス)の操作をそのまま写していた所: マスを正確に押して歩く・長押しで調べる(マウスのホバーや右クリックの代わり)・押している間だけ進む手の行為・設計の小さな記号のボタンが並ぶ編集・文字だけのリンク。
