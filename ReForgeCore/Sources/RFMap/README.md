# RFMap

地図(地形・目印・配置物・鉱脈・視界・経路)。原作 `ReForge.Core/Exploration/` の移植。依存は RFKernel だけ。

- 正の型は `WorldMap`(= `MapState`)と `MapLayer`。層は `LayerID`(地表は `"layer.surface"`)、層をまたぐ位置は `WorldPoint`。
- 生成は `WorldMap.generate(config:rng:)`。渡された `SeededRandom` を 1 回だけ進め、同じ seed からは同じ地図になる。三角関数は使わない(64 方位の整数の表)。
  地形と目印の指紋はテスト(`testGoldenFingerprint`)で固定している。
- 目印の位置関係(森の近道・川沿いの道・遠い残骸・岩山)は、書き込んだ地形を Pathfinder で実際に測って確かめる。
  保証を満たす配置が見つからなければ投げる(`MapGenerationError`)。未検証の地図に落とすのは `allowUnverifiedFallback` のときだけで、`generationReport.verified == false` に残る。
- 視界の円の判定は `VisionRule`(昼 8・夜 −3・灯り +4・最小 2、`inCircle` / `cells`)の 1 か所。仲間の既知・画面の明暗もこれを呼ぶ。
- 表示名は持たない。地形は `Biome`(中)/ `TerrainID`(外。`Biome.terrainID`)、配置物・鉱脈は ID だけ。名前と文字は Perception 層が引く。
- 保存の形に小数を入れない(設定の実数は 100 万分の 1 単位の整数で書く)。

## 保存した設定は再生成に使わない

保存した `WorldMap.config`(`MapGenerationConfig`)はその地図を作ったときの記録で、同じ seed から作り直すときの入力には使わない。
作り直すときは、その版のコードの既定の設定(`MapGenerationConfig(size:)`)から作る。保存済みの地図の地形・目印・配置物は保存の中身が正。

## 原作との違い(移動のコスト)

体力のコスト(千分率)は原作どおり: 整地 5・平地 10・森 20・岩場 30・遺跡 20、斜めは 1.4 倍(`(c*14+5)/10`)。違いは次のとおり。

| 地形 | 原作 | RFMap | 理由 |
|---|---|---|---|
| 川の流れ(`river`) | 水辺として歩ける(20) | 歩けない | 川を「渡る」選択に意味を持たせる |
| 浅瀬(`ford`) | なし | 40(平地の 4 倍) | 川を渡れる場所を限る |
| 岸の水辺(`water`) | 20 | 20 | 川沿いの道は岸を歩く |
| 角の切り抜け | 判定なし | 通れない 2 マスの間の角は斜めに抜けない | 川の角をすり抜けない |

森のコスト(20)は変えていない。100 seed の実測で、拠点 → 露頭の最安経路が森を踏むマスは最小 4・中央 6、
森を避けた道のコストは最安の最小 1.39 倍・中央 1.85 倍(保証は 1.2 倍以上)。
