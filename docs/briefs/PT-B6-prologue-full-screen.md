# PT-B6 序を、画面を覆う語りの場面に(Codex への説明書)

書いた人: architect(統合担当)。実装: Codex(relay:codex-impl)。土台: 統合の枝 `integration-c` の先頭(PT-B2 の後。PT-B5 と並ぶ優先度。小さいので B5 より先に出してよい)。
なぜ: オーナーの言葉「初手で文章を読ませるってのはそうじゃなくて、画面を覆ったような感じで述べるシーンを用意することだ。」今の序(W-16 の `PrologueLayer`)は、地図の上に重ねた層で、縦の余白(`AdLayout.contentGap`)と右上の設定のボタン(L-10a の別の窓)が序の上にも見え、安全域の外を覆っていない。
**決まり**: 語りの文はオーナーの物語。文言・行の数・順番は変えない。送りはタップだけ(時間で送らない。W-16 の規則のまま)。この単位は見せ方だけを決める。

物差し: 評価の軸「操作性」の OP-A1(送りのタップへの 0.1 秒以内の反応)・OP-C3(安全域の外まで収まる)・OP-D3(説明の文なしで送り方が分かる: ▼ と、押した瞬間に ▼ が沈む)・OP-J1(動きを減らす・文字の大きさに従う。文字の大きさを最大にしても行が欠けない)。

## 1. 場面として独立させる
- 序の間は、`GameScreen` の中の層ではなく、**画面全体の場面**にする: `RootView` の一番上に、`.ignoresSafeArea()` で安全域の外(ノッチ・ホームの線のまわり)まで覆う `PrologueScene` を置く。地図・帯・足元カード・タブ・余白は、序の間は作らない(描かない)。
- 右上の設定のボタン(`SettingsCornerWindows` の窓)は、序の間は隠す(`AppModel` に「角のボタンを出すか」を持ち、序の間は false。窓ごと `isHidden`)。序の間に設定を開く口は無くてよい(序は数十秒。時計は止まっている)。
- 背景は `InkColor.field` より一段暗い、序だけの地の色(art-director の色の表に 1 つ足す)。紙の上ではなく「覆われた」と分かるようにする。
- 終わり(最後の行の後のタップ)からの移り方: 文字が 0.6 秒で消え → 黒の間 0.3 秒 → 地図が 0.8 秒で灯る(ノアのまわりから外へ。HK-04 と同じ輪の見せ方を使えるなら使う)。帯・足元カード・タブは、W-01 の開示の規則どおりに後から出る(この単位では順番を変えない)。
- 「動きを減らす」の入では、移り方は 0.3 秒のフェードだけ。
- **PT-B8 の後**: 序の終わりの移りは、文字が消える 0.6 秒 → 黒 0.3 秒の後、地図ではなく PT-B8 の暗い場面へつなぐ。地図が灯る 0.8 秒は、暗い場面の終わり(最初の行為が受け付けられた時)に行う。

## 2. 比べる 3 つの見せ方(開発の設定の隠し項目で切り替え。既定は A)
| 案 | 文字の出方 | 間 | ▼(読み終えの合図) |
|---|---|---|---|
| A 1 行ずつ浮かぶ | 新しい行が 0.5 秒で浮かぶ(今の動きを全画面に) | 行が出終わってから 0.4 秒後に ▼ | 最後の行の後で、ゆっくり明滅(周期 1.4 秒) |
| B 1 字ずつ | 1 字 40ms で出る。出ている途中のタップは、その行を全部出す(送らない)。出終わった後のタップで次へ | 句読点の後は 120ms 足す | 同じ |
| C 段で出る | その場面の行を、全部いっぺんに 0.8 秒で浮かべる | — | 同じ |
- どの案も、前の行は消さずに上へ積む(画面に入りきらなくなったら、古い行から薄くして上へ流す)。文字は本文の書体で 19pt 以上、行間 1.6 倍、左右の余白 32pt、縦の中ほどより少し上に置く。
- 送りのタップは画面のどこでもよい(押せる範囲は全画面)。押した瞬間に ▼ が一度沈む(0.1 秒以内の反応)。
- 音: PT-B3 が入っていれば、送りのタップで `ui_page`(PT-B3 の生成の道具に足す。紙をめくる程度の短い音)、終わりの移りで `ui_ignite_first` を使わずに低い音 `ui_dawn` を 1 つ。PT-B3 がまだなら音は付けず、名前だけ B3 の表に足しておく。
- 触覚: 送りのタップに選択の触覚(軽)。序には強い触覚を付けない(音の設計の決まり: 序と夢には付けない、の例外として送りの軽い 1 つだけ)。

## 3. 画面の写真と短い動画
- 公開の層に試験の序の場面を置く: DEBUG のビルドだけが読む見本(アプリの `Debug/` の置き場。本番の束には入れない)に、中立の 3 行 × 2 場面(「試験の一行目」など)。`ScreenshotMode` に `prologue` を足し、`ScreenSnapshotTests` でその画面を 5 言語で撮る(序の文は見本のまま)。
- 短い動画: screens のジョブで、シミュレータの `xcrun simctl io booted recordVideo` を使い、`prologue` の起動から 3 回送って地図へ移るまでの数秒を撮る(UI テストからタップを送る)。案 A・B・C の 3 本。screens の成果物(artifact)に動画を足す(ログは成果物に出さない決まりのまま。動画は試験の見本の文だけを写す)。
- 撮れない場合(ランナーで録画が止まる等)は、その旨をジョブの要約に 1 行出し、ジョブは落とさない。
